在AES最终轮中，输入状态是一个4×4 字节矩阵，按列优先存储。设输入状态的四列为 \(s~0~, s~1~, s~2~, s~3~\)，每列叫做一个字，每个字的高位到低位依次为行 0、1、2、3 的字节。最终轮输出的四列记为 \(t~0~, t~1~, t~2~, t~3~)，最后一轮的轮密钥字为 \(rk[40], rk[41], rk[42], rk[43]\)。

T 表 \(Te_0, Te_1, Te_2, Te_3\) 中每个表项是 32 位字，其字节构成如下（从高到低）：
- \(Te_0[x] = (2\cdot S(x),\ S(x),\ S(x),\ 3\cdot S(x))\)
- \(Te_1[x] = (3\cdot S(x),\ 2\cdot S(x),\ S(x),\ S(x))\)
- \(Te_2[x] = (S(x),\ 3\cdot S(x),\ 2\cdot S(x),\ S(x))\)
- \(Te_3[x] = (S(x),\ S(x),\ 3\cdot S(x),\ 2\cdot S(x))\)

因此，通过掩码可以从不同表中提取出纯粹的 S 盒输出 \(S(x)\)：
- \(S(x) = (Te_2[x] \gg 24) \& 0\text{xFF}\)
- \(S(x) = (Te_3[x] \gg 16) \& 0\text{xFF}\)
- \(S(x) = (Te_0[x] \gg 8) \& 0\text{xFF}\)
- \(S(x) = Te_1[x] \& 0\text{xFF}\)

最终轮的计算公式（以输出列 \(t_k\) 为例）为：

\[
\begin{aligned}
t_k = &\ (Te_2[\,(s_k \gg 24) \& 0\text{xFF}\,] \ \&\ 0\text{xFF000000}) \quad \text{(行0字节)} \\
      &\ \oplus\ (Te_3[\,(s_{(k+1)\bmod 4} \gg 16) \& 0\text{xFF}\,] \ \&\ 0\text{x00FF0000}) \quad \text{(行1字节)} \\
      &\ \oplus\ (Te_0[\,(s_{(k+2)\bmod 4} \gg 8) \& 0\text{xFF}\,] \ \&\ 0\text{x0000FF00}) \quad \text{(行2字节)} \\
      &\ \oplus\ (Te_1[\,s_{(k+3)\bmod 4} \& 0\text{xFF}\,] \ \&\ 0\text{x000000FF}) \quad \text{(行3字节)} \\
      &\ \oplus\ rk[40 + k]
\end{aligned}
\]

式中：
- \(s_k \gg 24\) 取第 \(k\) 列的行 0 字节；
- \(s_{(k+1)\bmod 4} \gg 16\) 取第 \((k+1)\bmod 4\) 列的行 1 字节；
- \(s_{(k+2)\bmod 4} \gg 8\) 取第 \((k+2)\bmod 4\) 列的行 2 字节；
- \(s_{(k+3)\bmod 4} \& 0\text{xFF}\) 取第 \((k+3)\bmod 4\) 列的行 3 字节。

通过这四个查表操作，分别提取出对应行的 S 盒输出，并拼成一个 32 位字，再与轮密钥异或即得密文的一列。























Flush+Reload 攻击 AES-128 最终轮密钥 \(K^{10}\) 的核心原理基于以下关系：

\[
C = S(x) \oplus K^{10} = C \oplus S(x)
\]

其中：
- \(C\) 是已知的密文字节，
- \(x\) 是最后一轮输入状态的某个字节（未知），
- \(S(\cdot)\) 是 AES 的 S 盒，
- \(K^{10}\) 是待恢复的密钥字节。

攻击者监控每个 T 表（\(\mathrm{Te}_i\)）的第一个缓存行（对应输入值 \(0 \sim 15\)）。若某次加密后该缓存行未被访问（缓存未命中），则表明对应的输入字节 \(x\) **不可能** 是 \(0 \sim 15\) 中的任何一个。

因此，对于每一个可能的 \(l \in [0,15]\)，由 \(C = S(l) \oplus K^{10}\) 推导出的候选密钥值 \(K_{\text{cand}} = C \oplus S(l)\) 都不可能正确。于是我们在计数器 \(CK[pos][K_{\text{cand}}]\) 上加 1（表示该候选值被排除一次）。

经过大量加密样本，对每个密钥字节位置 \(pos\)，正确密钥值被排除的次数极少（因为它的真实输入 \(x\) 很少落在 \(0\sim15\) 内），而错误候选会被多次排除。最终选择被排除次数最少的候选作为恢复的密钥字节：

\[
K^{10}[pos] = \arg\min_{k \in [0,255]} CK[pos][k]
\]

这便是 Flush+Reload 攻击 AES-128 最终轮的数学原理。
