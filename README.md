# 处理器微架构侧信道漏洞安全测试技术研究

**处理器微架构侧信道漏洞测试平台（天津大学 2026 届毕业设计）**

## 1. 课题介绍

本课题聚焦处理器微架构测信道的安全测试，面向已有公开漏洞的复现与验证。研究内容包括：

1）整理相关的典型测信道案例，梳理威胁模型与攻击前提；

2）基于公开论文与开源样例，复现至少两类漏洞原型，结合高精度计时与性能计数器收集侧证据；

3）设计评测指标与脚本，量化泄露带宽、命中率、信噪比与跨核/跨进程可迁移性；

4）验证常见缓解措施（隔离策略、缓存冲洗、编译器或内核参数、微码与固件更新）的效果，对比前后差异；

5）形成可复用的实验说明与一键化演示，支持在平台上快速复现。
