## 1. 状态矩阵（State）

AES 的所有操作都在一个称为**状态（State）**的二维字节矩阵上进行。128 位（16 字节）的输入数据按列填充到 4×4 的矩阵中：

```
输入字节序列：in0, in1, in2, ..., in15
状态矩阵：
[ in0  in4  in8  in12 ]
[ in1  in5  in9  in13 ]
[ in2  in6  in10 in14 ]
[ in3  in7  in11 in15 ]
```

每个单元格是一个字节（8 位），矩阵的每一列称为一个“字”（32 位）。加密过程中，状态矩阵不断被更新，最终输出的密文也是从状态矩阵按列读取的 16 个字节。

---

## 2. 密钥扩展（Key Expansion）

AES-128 使用 128 位主密钥，需要扩展出 11 个 128 位的轮密钥（分别用于初始轮和后面 10 轮）。每个轮密钥也是 4×4 的字节矩阵（即 4 个字）。

### 2.1 符号约定
- 主密钥记为 `W[0], W[1], W[2], W[3]`，每个 `W[i]` 是一个 32 位字（4 字节）。
- 我们需要生成 `W[4]` 到 `W[43]`（共 44 个字），每 4 个字组成一个轮密钥：
  - 第 0 轮密钥（初始轮）：`W[0]~W[3]`
  - 第 1 轮密钥：`W[4]~W[7]`
  - ...
  - 第 10 轮密钥：`W[40]~W[43]`

### 2.2 扩展规则
对于 `i` 从 4 到 43：
- 如果 `i` 不是 4 的倍数（即 `i % 4 != 0`）：
  ```
  W[i] = W[i-4] XOR W[i-1]
  ```
- 如果 `i` 是 4 的倍数（即 `i % 4 == 0`）：
  ```
  W[i] = W[i-4] XOR SubWord(RotWord(W[i-1])) XOR Rcon[i/4]
  ```
  其中：
  - **RotWord**：将一个字的 4 个字节循环左移 1 字节（例如 `[a0,a1,a2,a3]` → `[a1,a2,a3,a0]`）。
  - **SubWord**：对字中的每个字节应用 S‑盒替换（S‑盒与加密时使用的 S‑盒相同）。
  - **Rcon**：轮常数，是一个 4 字节的值，其最右边三个字节总是 0，最左边字节为 `RC[j]`，`RC[1]=0x01`，之后 `RC[j]=0x02 * RC[j-1]`（乘法在 `GF(2^8)` 中进行）。例如：
    - Rcon[1] = (0x01, 0x00, 0x00, 0x00)
    - Rcon[2] = (0x02, 0x00, 0x00, 0x00)
    - Rcon[3] = (0x04, 0x00, 0x00, 0x00)
    - ...

通过这种方式，每个轮密钥都与主密钥及轮编号紧密相关，增强了密钥的随机性。

---

## 3. 加密轮结构

AES-128 加密由以下部分组成：

- **初始轮**：仅进行 **AddRoundKey**（与第 0 轮密钥异或）。
- **9 轮标准轮**：每轮依次执行 **SubBytes** → **ShiftRows** → **MixColumns** → **AddRoundKey**。
- **最终轮**：依次执行 **SubBytes** → **ShiftRows** → **AddRoundKey**（没有 MixColumns）。

下面详细解释每一步操作。

---

### 3.1 字节代换（SubBytes）

**目的**：提供非线性变换，混淆明文与密钥的关系。

**操作**：对状态矩阵中的每个字节，独立地通过一个固定的 **S‑盒（S‑box）** 替换为另一个字节。S‑盒是一个 16×16 的查找表，共 256 个值。例如，输入字节 `0x52`（行索引 5，列索引 2）对应输出 `0x00`。

**数学背景**：S‑盒的构造包含两步：
1. 在 `GF(2^8)` 中计算字节的乘法逆元（`0x00` 的逆元定义为自身）。
2. 对逆元应用一个仿射变换（可逆的线性变换加常数），以消除简单代数性质。

这种构造使得 S‑盒具有良好的非线性，能有效抵抗线性分析和差分分析。

---

### 3.2 行移位（ShiftRows）

**目的**：将字节在不同列之间移动，实现扩散。

**操作**：对状态矩阵的每一行进行循环左移，移位量随行号变化：
- 第 0 行：不移位。
- 第 1 行：循环左移 1 字节。
- 第 2 行：循环左移 2 字节。
- 第 3 行：循环左移 3 字节。

例如，移位前的状态矩阵：
```
[ a0 a4 a8  a12 ]
[ a1 a5 a9  a13 ]
[ a2 a6 a10 a14 ]
[ a3 a7 a11 a15 ]
```
移位后变为：
```
[ a0 a4 a8  a12 ]  (不变)
[ a5 a9 a13 a1  ]  (左移1)
[ a10 a14 a2 a6 ]  (左移2)
[ a15 a3 a7 a11 ]  (左移3)
```

这样，原来同一列的数据被分散到不同列，为下一步列混合做准备。

---

### 3.3 列混合（MixColumns）

**目的**：将每一列内部的四个字节进行线性混合，进一步增强扩散。

**操作**：将状态矩阵的每一列视为一个四项多项式，与固定多项式 `c(x) = 0x03·x³ + 0x01·x² + 0x01·x + 0x02` 在 `GF(2^8)` 中相乘，然后取模 `x⁴+1`。这个乘法可以用矩阵乘法表示：

```
[ s'0 ]   [ 02 03 01 01 ] [ s0 ]
[ s'1 ] = [ 01 02 03 01 ] [ s1 ]
[ s'2 ]   [ 01 01 02 03 ] [ s2 ]
[ s'3 ]   [ 03 01 01 02 ] [ s3 ]
```

其中 `s0, s1, s2, s3` 是某列的四个字节，`s'0, s'1, s'2, s'3` 是新列的四个字节。加法和乘法都在 `GF(2^8)` 中进行：
- **加法**：字节的异或（XOR）。
- **乘法**：遵循 `GF(2^8)` 的多项式乘法规则（使用不可约多项式 `x⁸ + x⁴ + x³ + x + 1`，即 `0x11B`）。

**简便计算**：乘以 `0x02` 相当于将字节左移一位，如果最高位为 1 则再异或 `0x1B`；乘以 `0x03` 可分解为 `(0x02) XOR (0x01)`，即先乘以 0x02 再异或原值。

列混合确保了单个字节的改变会影响到该列的所有四个字节，从而快速扩散到整个状态矩阵。

---

### 3.4 轮密钥加（AddRoundKey）

**目的**：将轮密钥混入状态，使加密依赖于密钥。

**操作**：将状态矩阵与当前轮的轮密钥矩阵进行逐字节异或（XOR）。轮密钥由密钥扩展生成。

---

## 4. 完整加密流程伪代码

```
输入：128 位明文块 plaintext，128 位密钥 key
输出：128 位密文块 ciphertext

1. 状态矩阵 State = plaintext 按列填充
2. 轮密钥数组 RoundKeys = KeyExpansion(key)   // 生成 11 个 128 位轮密钥

3. // 初始轮
   AddRoundKey(State, RoundKeys[0])

4. // 第 1 轮到第 9 轮
   for round = 1 to 9:
       SubBytes(State)
       ShiftRows(State)
       MixColumns(State)
       AddRoundKey(State, RoundKeys[round])

5. // 第 10 轮（最终轮）
   SubBytes(State)
   ShiftRows(State)
   AddRoundKey(State, RoundKeys[10])

6. 输出 ciphertext = State 按列读取的 16 字节
```

---

## 5. 解密简述

AES 解密是加密的逆过程，需要反向执行每一步并调用对应的逆函数：
- **逆字节代换（InvSubBytes）**：使用逆 S‑盒。
- **逆行移位（InvShiftRows）**：对每行进行循环右移。
- **逆列混合（InvMixColumns）**：乘以另一个固定的多项式矩阵（其系数为 `0x0B, 0x0D, 0x09, 0x0E` 等）。
- **轮密钥加（AddRoundKey）**：异或操作本身可逆，但使用轮密钥的顺序要与加密相反（从第 10 轮到第 0 轮）。

---

## 6. 总结

AES-128 的 10 轮结构通过**字节代换**提供混淆，通过**行移位**和**列混合**实现扩散，再通过**轮密钥加**引入密钥依赖。每一轮都使状态更加随机，经过 10 轮后，即使明文或密钥只有微小变化，密文也会产生巨大差异（雪崩效应）。这种精心设计使得 AES 至今仍是安全的对称加密算法，被广泛应用于各类安全协议中。
