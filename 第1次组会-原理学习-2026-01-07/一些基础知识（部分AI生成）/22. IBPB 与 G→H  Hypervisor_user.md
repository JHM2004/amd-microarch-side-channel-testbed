IBPB 与 G→H | Hypervisor_user 正式速解

---

### IBPB（Instruction Branch Prediction Barrier）

**功能**：CPU指令，**立即清空分支预测器**（BTB/BHB）。

**用途**：防止**跨进程/跨VM**的分支预测攻击（如Spectre）。

**AMD特异性**：Zen4+支持，**Zen1-3无硬件实现**，依赖软件序列化（如`lfence`）。

---

### G→H | Hypervisor_user（具体目标）

**定义**：**Guest VM攻击其自身Hypervisor的用户态组件**。

**角色映射**：
- **G** = Guest（客户机虚拟机）
- **H** = Host（物理宿主机）
- **Hypervisor_user** = **Host上的特权用户态程序**（如QEMU、kvm-tool）

**攻击路径**：
- **Guest User** → **Host User（QEMU）** → **窃取Host秘密**（磁盘密钥、VPC配置）

**具体目标**：
- **QEMU的MMIO处理函数**（system/memory.c）
- **KVM用户态工具**（kvm-tool、kvm-qemu）
- **云基础设施密钥**（磁盘加密密钥、VPC证书）

**攻击载体**：**MMIO写入**触发QEMU间接调用，利用BTB污染+推测执行窃取机密。

**权限流**：
```
Guest User（攻击者） → Host User（QEMU） → Host Kernel（KVM） → 窃取Host秘密
```

**关键**：Hypervisor_user是**Host上的特权用户态**，**不是Guest用户态**，但**必须处理Guest请求**，形成强制共存攻击面。
