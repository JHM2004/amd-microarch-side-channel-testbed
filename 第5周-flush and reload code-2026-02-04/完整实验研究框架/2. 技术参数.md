## 编译选项

```makefile
CC = gcc
CFLAGS = -O0 -g -march=native -Wall -fPIC -Wno-unused-result -fno-stack-protector
LDFLAGS = -ldl -pthread -lm
```

| 选项 | 说明 |
|------|------|
| `-O0` | 关闭优化，确保内存访问不被优化掉（对侧信道攻击很重要） |
| `-g` | 包含调试信息 |
| `-march=native` | 针对本机CPU架构优化 |
| `-fPIC` | 生成位置无关代码（用于共享库） |
| `-fno-stack-protector` | 禁用栈保护，减少运行时开销 |

## 计时方式

使用 **RDTSC** (Read Time-Stamp Counter) 指令：

```c
static inline uint64_t rdtsc() {
    uint64_t a, d;
    asm volatile ("mfence\nlfence\nrdtsc" : "=a"(a), "=d"(d));
    return (d << 32) | a;
}
```

| 特性 | 说明 |
|------|------|
| 精度 | CPU 时钟周期级（~0.3ns @ 3GHz） |
| 隔离指令 | `mfence` + `lfence` 确保指令序列化和内存序 |

## 测量开销控制

1. **多次测量取最小值**：每次测量重复 3 次，取最小值减少噪声
2. **CPU 亲和性绑定**：使用 `sched_setaffinity()` 绑定到固定核心（Core 0）
3. **内存屏障**：使用 `mfence`/`lfence` 隔离测量区域
4. **缓存行对齐**：S-box 条目按 64 字节（缓存行大小）对齐
