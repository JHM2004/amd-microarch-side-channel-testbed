## 命令格式

```bash
sudo ./build/test_mitigation [选项]
```

## 参数详解

### 1. 基础选项

| 参数 | 长格式   | 说明                 |
| ---- | -------- | -------------------- |
| `-h` | `--help` | 显示帮助信息         |
| `-a` | `--all`  | **测试所有缓解措施** |

**示例**：
```bash
# 显示帮助
sudo ./build/test_mitigation -h

# 测试所有缓解措施（默认3轮迭代）
sudo ./build/test_mitigation -a
```

---

### 2. 迭代次数控制

| 参数 | 长格式         | 参数值   | 说明                   |
| ---- | -------------- | -------- | ---------------------- |
| `-i` | `--iterations` | N (1-10) | **每轮测试的迭代次数** |

**示例**：
```bash
# 测试所有缓解措施，每轮测试3次
sudo ./build/test_mitigation -a -i 3

# 测试所有缓解措施，每轮只测试1次（快速测试）
sudo ./build/test_mitigation -a -i 1
```

**说明**：
- 迭代次数越多，统计结果越可靠
- 建议值：1（快速测试）、3（标准测试）、5-10（精确测试）
- 每次迭代约5-7秒

---

### 3. 特定缓解措施对比测试

| 参数 | 长格式      | 参数值     | 说明                     |
| ---- | ----------- | ---------- | ------------------------ |
| `-c` | `--compare` | TYPE (1-7) | **对比特定缓解措施效果** |

**缓解措施类型对照表**：

| TYPE | 缓解措施                   | 说明                                          |
| ---- | -------------------------- | --------------------------------------------- |
| `1`  | **CPU Pinning**            | CPU亲和性绑定（攻击者和受害者绑定到不同核心） |
| `2`  | **Cache Flush**            | 频繁缓存冲洗                                  |
| `3`  | **Noise Injection**        | 噪声注入（随机内存访问）                      |
| `4`  | **Access Obfuscation**     | 访问混淆（随机化访问模式）                    |
| `5`  | **Process Isolation**      | 进程隔离（不同进程空间）                      |
| `6`  | **Core Isolation**         | 核心隔离（不同物理核心）                      |
| `7`  | **Disable Hyperthreading** | 禁用超线程                                    |

**示例**：
```bash
# 对比CPU Pinning效果（测试2轮）
sudo ./build/test_mitigation -c 1 -i 2

# 对比Cache Flush效果（测试3轮）
sudo ./build/test_mitigation -c 2 -i 3

# 对比Process Isolation效果（测试1轮）
sudo ./build/test_mitigation -c 5 -i 1
```

**输出内容**：
- 基准测试（无缓解措施）结果
- 带缓解措施测试结果
- 缓解效果百分比（攻击成功率降低）
- 性能开销百分比

---

### 4. 跨核可迁移性测试

| 参数 | 长格式         | 说明                   |
| ---- | -------------- | ---------------------- |
| `-x` | `--cross-core` | **测试跨核心迁移攻击** |

**示例**：
```bash
# 测试跨核可迁移性
sudo ./build/test_mitigation -x
```

**测试场景**：
1. **Core 0 → Core 0**：同核心/超线程（共享L1/L2缓存）
2. **Core 0 → Core 1**：相邻核心（共享L3缓存）
3. **Core 0 → Core 1**：跨CCX边界（共享L3缓存）

**输出内容**：
- 每种场景的攻击成功率
- 迁移性分析结论

---

### 5. 跨进程隔离测试

| 参数 | 长格式            | 说明                   |
| ---- | ----------------- | ---------------------- |
| `-p` | `--cross-process` | **测试跨进程隔离效果** |

**示例**：
```bash
# 测试跨进程隔离
sudo ./build/test_mitigation -p
```

**测试场景**：
1. **同用户，同命名空间**：同一进程上下文
2. **同用户，不同命名空间**：不同命名空间
3. **不同用户**：不同用户权限

**输出内容**：
- 每种隔离级别的攻击成功率
- 隔离效果分析结论

---

## 完整使用示例

### 示例1：快速测试所有缓解措施
```bash
# 每轮测试1次，快速完成
sudo ./build/test_mitigation -a -i 1
```

### 示例2：标准测试（推荐）
```bash
# 每轮测试3次，平衡速度和准确性
sudo ./build/test_mitigation -a -i 3
```

### 示例3：精确对比特定缓解措施
```bash
# 对比CPU Pinning，测试5轮
sudo ./build/test_mitigation -c 1 -i 5

# 对比Cache Flush，测试5轮
sudo ./build/test_mitigation -c 2 -i 5
```

### 示例4：完整测试流程
```bash
# 1. 测试所有缓解措施
sudo ./build/test_mitigation -a -i 3

# 2. 测试跨核可迁移性
sudo ./build/test_mitigation -x

# 3. 测试跨进程隔离
sudo ./build/test_mitigation -p

# 4. 详细对比最有效的缓解措施
sudo ./build/test_mitigation -c 6 -i 5  # Core Isolation
```

## 输出文件

测试完成后会生成以下文件：

```
results/
├── mitigation_report.txt          # 缓解措施效果报告
├── mitigation_analysis_report.md  # 完整分析报告
├── attack/                        # 攻击轮次数据（JSON）
├── calibration/                   # 校准数据
├── metrics/                       # 量化指标（JSON）
└── figures/                       # 可视化图表（PNG）
```
